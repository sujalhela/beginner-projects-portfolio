# Student Marks Analyzer

A small Python exercise that summarizes fictional student marks.

## Concepts practised

- Dictionaries, lists, loops, and functions
- Calculating averages
- Conditional logic and formatted output

## Run

```bash
python student_marks.py
```

The student names and marks are invented sample data. The grade bands are illustrative and are not an official grading policy.

## Ideas to improve it

- Read student records from a CSV file.
- Validate that marks are between 0 and 100.
- Add unit tests.
