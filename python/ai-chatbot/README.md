# Beginner AI Chatbot

A command-line conversational chatbot built with Python and the official OpenAI SDK. It sends user messages to the OpenAI Responses API and uses the previous response ID to continue the conversation.

## Features

- Interactive terminal chat loop
- Multi-turn conversation context
- Configurable model through the `OPENAI_MODEL` environment variable
- Basic handling for missing API keys and API errors

## Requirements

- Python 3.10+
- An OpenAI API key
- API access and available billing/credits on the OpenAI Platform

## Setup

1. From the repository root, install the dependency:

   ```bash
   pip install -r requirements.txt
   ```

2. Create an API key in the [OpenAI API dashboard](https://platform.openai.com/api-keys).

3. Set the key as an environment variable. Do not paste it into the Python file or commit it to GitHub.

   **Windows PowerShell:**
   ```powershell
   $env:OPENAI_API_KEY="your_api_key_here"
   ```

   **macOS / Linux:**
   ```bash
   export OPENAI_API_KEY="your_api_key_here"
   ```

4. Run the chatbot:

   ```bash
   python python/ai-chatbot/chatbot.py
   ```

Optional model override:

```bash
# PowerShell
$env:OPENAI_MODEL="gpt-5.5"

# macOS / Linux
export OPENAI_MODEL="gpt-5.5"
```

## Example interaction

```text
Beginner AI Chatbot
You: What is a Python list?
Bot: A Python list is an ordered collection ...

You: Give me a short example.
Bot: numbers = [1, 2, 3]
```

The response above is illustrative; actual replies are generated by the selected model.

## How it works

1. The user enters a message in the terminal.
2. Python sends it to the OpenAI Responses API.
3. The API returns a model-generated response.
4. The program stores the response ID and supplies it on the next turn to maintain conversational context.

## Security and cost notes

- Never commit API keys, passwords, or private credentials.
- API usage may incur charges; check current pricing and usage limits before running the app.
- Do not send sensitive personal information to the chatbot.
- This is a small learning project, not a production-ready service.
