# Sales Data Summary

A beginner Python exercise using the built-in `csv` module to summarize fictional sales records.

## What it does

- Reads product, quantity, and unit price from a CSV file.
- Calculates total revenue.
- Groups revenue by product and sorts products by revenue.
- Checks required columns and rejects invalid or negative values.

## Run

```bash
python sales_summary.py
```

The included CSV contains invented sample data for practice. It is not real business data.

## Ideas to improve it

- Add dates and monthly summaries.
