# SQL Practice Queries

A beginner collection of SQLite-compatible queries using a fictional orders table.

## Topics

- Creating a table and inserting sample rows
- Selecting and filtering data
- Calculating revenue
- GROUP BY, COUNT, SUM, and AVG
- Sorting query results

## How to practise

Open `practice_queries.sql` in SQLite or an online SQLite editor and execute it from top to bottom. The table uses fictional data.

## Ideas to improve it

- Add a customers table and practise JOIN.
- Add order dates and practise monthly grouping.
- Write a question before each query, then check whether the result answers it.
